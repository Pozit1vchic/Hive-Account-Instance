# Hive audit and delivery notes — 2026-10-29

## Fixed in this pass

- Credential batches previously waited for each browser to close; up to four independent sign-in sessions are now allowed concurrently (two by default), with one cancellation source and serialized verified account writes. Browser discovery and first download are serialized to avoid competing downloads. The sign-in button and security challenges remain user-controlled.
- Sign-in checks for the OneTrust cookie-consent acceptance button on Roblox pages, including delayed rendering. The button handler is exercised with a simulated banner on the real Roblox origin; the actual banner was not presented in the test session, so its current live selector remains unconfirmed.
- Switch focus no longer changes track dimensions. Honeycomb drawing now covers the workspace using one geometry; tool headers use translucent layered gradients. These are WPF glass-inspired surfaces, not native desktop background blur.
- Game window width and height are saved and applied in physical pixels to linked windows. Tested on a controlled window, not a live Roblox client.
- MCP uses stdio and a current-user-only Windows named pipe; it lists account metadata/status and enqueues a specified account and Place/Job target. It does not return passwords, cookies or tickets and has no network listener. Processes under the same Windows account can access the pipe; this boundary does not defend against hostile software running as that user.

## Open limitations

- A full parity/security audit has not been completed; this file records observations from the affected workflows, not a certification. Roblox presence/friend discovery and in-process disconnect detection remain incomplete. Multi-instance, private-server and follow-user live joins still need end-to-end verification.
- The cookie selector may change and the banner may be hosted differently by region. Roblox authentication, 2FA, CAPTCHA, rate limits and server authorization remain controlled by Roblox. No claim is made about lower CAPTCHA rates.
- Auto-rejoin sees a linked process exit, not a disconnect while the client stays open. Account state is based on a confirmed process association, not Roblox presence.
- Roblox supports changing FPS cap inside the client, but no stable documented external API was found for setting it from Hive. There is no Hive FPS cap setting yet; do not modify undocumented client flags or promise that an external limit will work.
- The control service is local only. Internet/phone access requires a separate design for pairing, encryption, revocation, authorization and connection routing. The current pipe or MCP stdio must not be exposed directly to the internet.
- The user will provide the replacement Hive logo. No substitute logo was introduced.
- Installer compilation needs Inno Setup's `ISCC.exe`; portable and installer packaging are produced locally, not automatically published as GitHub releases. Browser downloads and application data stay out of the source repository.

NuGet vulnerability inspection on 2026-10-29 reported no known vulnerable direct or transitive packages from the configured source. This covers published advisories, not undiscovered vulnerabilities or the vendored browser plugin source.
