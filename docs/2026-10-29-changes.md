Protocol-wrapper tracker matching is covered by tests. Native 800×500 resizing is checked on a controlled test window; joining a live game is not part of the automated suite.
- Groups, favorites, saved places, batch queueing, metadata export, SQLite backup, Network Log and graceful selected-game closure extend the RAM-inspired workflow.
- Browser sign-in waits for manual final submission and verification. Unchanged-cookie validation is throttled; rate limits pause checking/import. No CAPTCHA solver, challenge bypass, proxy rotation or stronger fingerprint-evasion layer was added, and CAPTCHA frequency has not been measured.

The UI uses a consistent Segoe UI family, stable SVG stroke widths, shared tool-window chrome, aligned table cells, rounded sliders and unified dialog spacing. Compact main view and all preference categories are rendered by the smoke suite.

Queue policy, cancellation, rejoin limits, singleton ownership/release, share resolution and encrypted target/profile persistence are tested with isolated fixtures. A real two-client game session, real private-server admission and live follow-user joins have not been verified. Auto-rejoin currently detects a linked process exit, not a disconnected game that remains open; friend-presence discovery and deeper client controls remain parity work.
