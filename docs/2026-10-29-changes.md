# 2026-10-29 repair and workflow pass

## Verified behavior

- Account records and encrypted sessions remain in the existing local SQLite database. The live database contained three accounts and three sessions when investigated; no production data was deleted or replaced. Startup chooses a visible account. A separate process now verifies reopening metadata, DPAPI secrets, groups, favorites and launch preferences.
- Place ID, Job ID, saved places and favorites persist through atomic preference writes.
- Manual login opens immediately; addition progress uses neutral text, errors are explicit, and successful modal confirmation is checked separately. Browser cleanup does not turn a saved account into a failed result.
- Preferences uses three fixed-order categories. The executable-path picker is removed. Theme brushes transition in place; checkbox templates are not clipped.
- The browser reuses one private page, closes the initial blank page and restores normal 820×600 bounds. Real Chrome/Stealth navigation, cookie roundtrip and one-page/window bounds pass.
- Launch requests include the JSON body/content type required by Roblox. A live session previously reproduced 415; after repair the ticket endpoint returned 200. Protocol-wrapper tracker matching is covered by tests. Native 800×500 resizing is checked on a controlled test window; joining a live game is not part of the automated suite.
- Groups, favorites, saved places, batch queueing, metadata export, SQLite backup, Network Log and graceful selected-game closure extend the RAM-inspired workflow.
- Browser sign-in waits for manual final submission and verification. Unchanged-cookie validation is throttled; rate limits pause checking/import. No CAPTCHA solver, challenge bypass, proxy rotation or stronger fingerprint-evasion layer was added, and CAPTCHA frequency has not been measured.

## Remaining functional scope

A full browser-profile library, configurable parallel launch policy, client multi-instance support, automatic rejoin, private-server/follow-user launching and advanced Roblox account mutations remain separate work. The feature transfer is substantial but is not a claim of complete RAM parity.
