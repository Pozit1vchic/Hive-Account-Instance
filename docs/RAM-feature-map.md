# RAM feature map — 2026-11-05

Compared the archived upstream RAM `AccountManager.Designer.cs`, `Forms/AccountUtils.Designer.cs` and `Forms/SettingsForm.Designer.cs` with Hive. The reference checkout is ignored and is not compiled into Hive.

| RAM capability | Hive state |
|---|---|
| Manual login, User:Pass, cookies, custom URL + JavaScript | Implemented; interactive Roblox challenges remain required |
| Account removal, username/password/combo/cookie/profile/user-ID copy | Implemented |
| Username masking, alias and description | Table-name masking, editable alias and description implemented; masking is cosmetic and other windows can still show names |
| Groups and account moves | Implemented; RAM group-copy and expand/collapse controls are not implemented |
| Place, Job, private server and follow user ID | Follow-by-name, account-specific targets, recent Place IDs and paged public server browsing implemented; game metadata is not implemented |
| Async launches, delay, multi-instance and automatic rejoin | Implemented for process exits; detection of disconnect while the process remains open is not implemented |
| Session refresh and account checks | Implemented with backoff; RAM plaintext, default Windows DPAPI and password-locked account files are supported |
| Roblox presence | Explicit on-demand lookup implemented; periodic refresh and online-friends views are not implemented |
| Account privacy, password, email, display name, friends and group mutations | Official account/security/privacy pages open interactively; direct mutations, friend and group tools are not implemented |
| Windows startup, recent games, FPS and client flags | Opt-in Windows startup and recent Place IDs implemented; FPS and client flags are not implemented |
| Theme editor | Light/Dusk and accent choices exist; full custom theme editor is not implemented |
| Local API / account control | Optional current-user MCP status/launch implemented; RAM web server and remote phone access are not implemented |
| Authentication ticket / rbx-player link copy | Not implemented; these values grant account access and must not be logged |
| Custom fields, detail dump, age alerts and account backup | Encrypted custom fields (including RAM import) and SQLite backup implemented; detail dump and aging alerts are not implemented |

A manually requested presence lookup does not identify a local process. Usernames masked in the table can remain visible in other windows, the clipboard and logs generated by Roblox itself.
