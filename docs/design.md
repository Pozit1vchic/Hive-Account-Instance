# Hive interface direction

The reference image informed surface hierarchy and depth rather than a direct theme copy. The requested white honeycomb identity remains the default.

- Canvas: #F4F5F8. Raised surfaces: #FFFFFF. Text: #29313F. Muted text: #828896. Lines: #E7E9F0. Honey accent: #DFA740.
- Segoe UI Variable Text/Segoe UI keeps account data legible; the title is 22px, controls 12px, quiet annotations 10–11px.
- Primary actions use a restrained honey gradient and colored ambient shadow. Neutral actions stay flat; cards receive a single soft elevation shadow. Honeycomb lines live behind the upper toolbar rather than below table text.
- The primary workspace is a three-column account table. Details and Session share the narrower inspector, so saving does not require scrolling on the default window size.
- Button hover lifts 1.5px over 140ms; pressing scales to 97% over 80ms; window content enters over 200ms. Motion is disabled by the application switch or Windows reduced-animation setting.
- SVG source assets are embedded locally and rendered using their vector path geometry. There are no emoji icons or remote image dependencies.
- Settings has Appearance, Privacy, Sessions and Browser categories, saved immediately. Light/Dusk and Honey/Iris/Ocean use the same hierarchy.

Visual regression artifacts are generated by the smoke runner in `artifacts/`. The screenshots use isolated fixture accounts, not user data.

## Settings refinement

Reviewed [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) and [theme-factory](https://github.com/anthropics/skills/blob/main/skills/theme-factory/SKILL.md), alongside [Linear's design refresh](https://linear.app/now/behind-the-latest-design-refresh) and [Raycast Settings](https://manual.raycast.com/settings). These informed hierarchy, predictable placement and coherent themes; no preset artifact theme was imported.

Settings now uses a custom title bar, a separate navigation surface, a live vector preview of the selected palette, explicit selected theme/accent controls, and compact parameter rows. Appearance fits at 880x680 without scrolling. The redundant dark-mode toggle and theme status text were replaced by a two-option segmented control. Toggles transition over 160ms and honor the same reduced-motion rules as buttons. Save status reports write failures rather than claiming success.
